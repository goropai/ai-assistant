This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

# Спіді — голосовий помічник-робот (Android)

Kotlin, minSdk 25, targetSdk 34, лише armeabi-v7a. Основний пристрій — Samsung Galaxy J5 (Android 7.1).
Користувачі україномовні: тексти, коментарі, коміти й журнали — українською. `firmware/` — прошивка
колісної платформи (ESP32, HTTP по Wi-Fi), окремий проєкт зі своїм README.

## Збірка й перевірка

- Перед першою збіркою: `local.properties` з `local.properties.example` (моделі за замовчуванням, голос,
  яскравість, шлях до ключа підпису). API-ключі не вшиваються — їх вводять на телефоні в налаштуваннях.
- `.\gradlew.bat testDebugUnitTest assembleDebug --console=plain -q` — JVM-тести (справжній org.json) і APK.
  Один клас тестів: `.\gradlew.bat testDebugUnitTest --tests "com.speedy.assistant.SchoolTest"`.
- Встановлення: `adb -s <пристрій> install -r app\build\outputs\apk\debug\app-debug.apk`
  (Wi-Fi-adb на J5 часто відпадає — тоді кабелем і `adb tcpip 5555`).
- Голос без мікрофона (лише debug-збірка):
  `adb shell am broadcast -a com.speedy.assistant.debug.HEAR --es text "'фраза'"` (внутрішні лапки обов'язкові).
  Йде одразу в `handle()` (минаючи `onHeard`, тож без «Спіді» на початку), перериває поточну дію; якщо урок
  чекає відповіді — це відповідь. З bash — саме `--es text "'фраза'"`: зайві лапки потрапляють у текст.
  Відповіді Спіді в журналі — `D/Assistant: каже: …`; щойно після встановлення приймач ще не готовий (~20 с).
- Реліз: збільшити versionCode/versionName в `app/build.gradle.kts`, закомітити, `release.ps1 -Notes "…"`
  (потрібен GH_TOKEN). Примітки Спіді читає вголос — коротко й так, щоб звучало природно.
- Регулярні вирази в Kotlin-рядках (`"\\s"`) легко ламаються при правках через shell-heredoc чи скрипти
  (подвійний `\\` стає одинарним) — такі місця правити інструментом редагування або перевіряти після.

## Архітектура (що видно лише з кількох файлів)

- **`MainActivity`** лише збирає залежності (камери, слух, база, налаштування, сторож, VLC…) і передає їх
  у конструктор **`Assistant`** — оркестратора: усі рішення "що робити з фразою" там.
- **Шлях фрази**: `VoiceListener` (Google SpeechRecognizer; офлайн Vosk — без інтернету й поки дзвонить
  будильник) → `Assistant.onHeard` (PIN-віконце, відповідь уроку, сторож, реакції на факт/пропозицію уроку,
  чекання імені тощо) → `WakeWord` ("Спіді" будь-де у фразі) → `handle(command)`.
- **`handle`** спершу пробує локальні розбирачі без моделі — кожен `object …Commands.parse()` у своєму
  пакеті (guard, school, LocalCommands, settings, phone/EventParser, night, translate, media, books, news,
  phone/Hands, weather…), і лише потім `askModel` — агентний цикл: модель відповідає JSON `AgentReply`
  (`say`, `mood`, `action`: look / listen / search / move / command, `remember`); look/listen/search
  повертають результат моделі ще раз.
- **Інструменти моделі**: дія `command` виконується лише через білий список `runModelCommand`. Три місця
  мусять збігатися: опис форм у системному промпті `Brain`, `runModelCommand` і `ModelCommandsTest`
  (тест повторює той самий ланцюжок розбирачів). Налаштування, PIN, знайомства, вимкнення сторожа — моделі ні.
- **Зайнятість і мікрофон**: усе, що говорить чи слухає, іде через `runBusy {}` — вимикає слух на час дії й
  вмикає назад, якщо `micFree()` (не грає аудіо у VLC, не нічний режим, не сторож). `quiet()` — нічний режим
  чи сторож: Спіді нічого не каже сама (нагадування — вібрацією).
- **Пауза в розмові** (`initiative/PauseCheck`): після відповіді моделі 20 с тиші → ~хвилину кожні 9 с
  запис 4 с (розпізнавач на цей час зупинено) + передня камера (PresenceWatcher), через раз задня (знімок +
  локальний детектор). Мовлення й Gemini → звук моделі; людину видно двічі → одна репліка; нікого → тихо
  кінець. За паузу — одна репліка (`pausedOnce` скидає лише справжня фраза людини).
- **Пам'ять речей** (`things/`): `PresenceWatcher.onThumb` (мініатюра 16×12) → `SceneChange` (кімната
  змінилась, завмерла, нікого в кадрі; ≤ 4/год, ≥ 15 хв) → фото спереду → `ConfiguredLlm.generateJson(…, image,
  paidOnly = thingsPaidOnly)` → `ThingMemory` (`files/things.json`, 30 днів). "Де мої …" — `ThingCommands` до
  FORGET_THAT; не пам'ятає — далі до моделі. Зникла річ — лише після 2 оглядів без неї (модель пропускає).
- **Камера**: `PresenceWatcher` (передня, ML-детектор + обличчя) працює, лише коли Спіді вільна
  (`updatePresence` у MainActivity; під час уроків — теж); `CameraSnapshot` бере камеру для фото моделі;
  сторож (`guard/GuardCamera`) — свою прив'язку, тоді PresenceWatcher вимкнено.
- **Мозок**: `ConfiguredLlm` вибирає клієнта на кожен запит за налаштуваннями (Claude чи Gemini; для Gemini —
  два ключі й режим, перемикання при вичерпаній квоті). `GeminiClient` перебирає моделі (`GeminiModels`
  пам'ятає, які відпочивають). `generateJson` — окремі запити поза розмовою (теми уроків, факти); `search` —
  пошук через модель (запасний — Вікіпедія).
- **Дані**: люди, обличчя, голоси, профілі, тварини — SQLite (`data/SpeedyDb`, без Room); решта — JSON у
  `filesDir` через `writeTextAtomic` (пам'ять, нагадування, прогрес уроків, книги, медіа). Профіль
  (`people/Profiles`) — це те, що модель отримує як "[про співрозмовника: …]".
- **Тестованість**: логіку без Android тримаємо в чистих `object`/класах (розбирачі команд, `…Text`, генератори
  промптів, прогрес) — їх і покривають JVM-тести в `app/src/test`.

## Правила

- Реальні імена людей не потрапляють у код, коментарі, тести й коміти — лише умовні (Тарас, Ліна, Костя…).
- Налаштування, PIN і системні доступи — лише за PIN батьків; моделі налаштування не відкриваємо.
- Комітити й пушити — лише на прохання.

## Обмеження платформи (J5 / Android 7.1) — перевірено, не обходити наосліп

### Звук і розпізнавання мовлення
- **Google SpeechRecognizer не віддає звук**: `onBufferReceived` — 0 байт. Тож для фраз, розпізнаних
  Google, немає ні висоти голосу, ні відбитка голосу.
- **Мікрофон — лише одному**: паралельний AudioRecord, поки слухає Google (чи камера пише відео зі звуком),
  отримує тишу. Записати "для себе" одночасно з Google не можна.
- Висоту голосу міряє лише вартовий (`SoundGate`, ~0.6–0.85 с до передачі Google) і офлайн-шлях (Vosk).
  Якщо слухати одразу (`listenNow`, напр. на уроках) — вартового немає, висоти немає.
- Google займає ексклюзивний аудіофокус і глушить будильник/таймер — поки дзвонить, його не вмикаємо.
- Коротке одне слово ("три") Google інколи відкидає як NO_MATCH — беремо проміжний результат.
- Vosk (vosk-model-small-uk) розпізнає гірше за Google; граматика (обмежений словник) з цією моделлю
  повертала порожнє; англійської не знає. Модель вантажиться ~40–60 с після запуску.

### Хто говорить (дитина чи дорослий)
- Голосом **не розрізняємо**: відповіді на уроках слухає Google (див. вище — звуку немає).
- На уроках — **камерою**: урок для дитини, а найближче обличчя — знайомий дорослий → відповідь не
  зараховуємо (`adultAnswering`). Обмеження: коли в кадрі обоє, "говорить" той, чиє обличчя ближче;
  працює, лише якщо в профілі дорослого записано вік ADULT.
- У розмові — **за змістом**: модель отримує "[діти вдома: …]" і правило впізнавати дитину зі слів
  (лічилки, дитяча вимова), навіть коли камера бачить дорослого.
- Можливий шлях (свідомо НЕ зроблено): уроки слухати власним записом — висота й відбиток голосу,
  текст через Vosk (українська) або Gemini (англійська, звук у моделі). Ціна: +1–3 с на відповідь,
  гірше розпізнавання, англійська з Claude не працює, оцінку вимови довелося б перебудувати.
  Висота голосу маму від дитини надійно не відрізняє (180–250 Гц проти 250–400 Гц); відбиток голосу
  на 1–2 слова слабкий.

### Будильник
- Під сигнал будильника голос майже не чути (мікрофон поруч із динаміком) — "вимкни будильник"
  голосом ненадійне; притишування будильника на час фрази спрацьовувало від його ж гудків (прибрано).
- Годинник Samsung ігнорує `AlarmClock.ACTION_DISMISS_ALARM` і не має кнопки в сповіщенні —
  вимикаємо натисканням "Відхилити" у спливному вікні через службу спеціальних можливостей (дотик до Спіді).
- Сигнал пульсує: "дзвонить" тримаємо ще 3 с після гудка.

### Камера, моделі, інше
- Дві камери одночасно J5 не тримає — сторож перемикає передню й задню по черзі.
- Звук моделі приймає лише Gemini; Claude — ні (отримує текстову примітку).
- TTS сам відмінює числа після прийменників ("до дванадцятьох") — текст має бути граматичним
  ("від плюс 4 градусів"), решту не обходимо.
- Play Маркет на J5 падав під час перевірки Play Protect (`VerifyAppsInstallTask`) — самооновлення зависало.
  Перемикача в Play Маркеті замало: 0.16.1 зависла, бо перевірка під час встановлення лишалась
  (`package_verifier_enable=1`). На прохання власника (на J5 ставимо лише ми) — `settings put global
  package_verifier_enable 0`. Play Маркет може повернути 1 — тоді знову зависне; перевірити цей прапорець.
  Зависло — ставити через adb (`push` у /data/local/tmp + `pm install -r`).
- **NewPipe** лише шукає (результат натискає `SpeedyHands`); багато дитячих відео YouTube у ньому —
  "Вміст недоступний" (тоді "Відкрити в браузері"). Посилання на відео відкриває вікно вибору дії.
- **Служба спеціальних можливостей**: `adb shell uiautomator dump` перезапускає її (міні-Спіді зникала —
  тепер `onConnected` показує знову; не плутати з багом). Вікно відео NewPipe ("surfaceView") обхід
  дерева не бачить — лише `findAccessibilityNodeInfosByViewId`.
- Повернути Спіді на екран із фону: `startActivity` на J5 переносить задачу, але система знову відновлює
  інший застосунок — працює `ActivityManager.moveTaskToFront` (дозвіл REORDER_TASKS).
- Оновлення вбиває застосунок — `RestartAfterUpdate` (MY_PACKAGE_REPLACED) повертає Спіді на екран.
