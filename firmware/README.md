# Колісна платформа Спіді

Залізо:
- **ESP32-DevKitC (ESP-WROOM-32, 38 pin)** на платі розширення — мозок платформи, Wi-Fi.
- **Драйвер L9110S** (1 шт.) — 2 канали, до ~0.8 А на канал, 2.5–12 В.
- **Шасі 4WD** з 4 TT-моторами (3–6 В), дисками енкодерів і відсіком для батарей.

**Один L9110S на 4 мотори.** Моторів 4, а каналів 2, тож мотори кожного боку з'єднуються
паралельно: лівий бік на канал A, правий на канал B. Їде як танк. Щоб не перевантажити драйвер
(~0.8 А на канал), прошивка плавно розганяє мотори й обмежує ШІМ. Не тримай колеса заклиненими:
якщо платформа вперлася й гуде — драйвер гріється. Друга плата L9110S (по каналу на мотор) зніме
це обмеження: у `src/main.cpp` тоді постав `TWO_DRIVERS = true`.

## Підключення (одна плата L9110S)

| ESP32 | L9110S | Мотори |
|---|---|---|
| GPIO25 | A-IA | лівий бік |
| GPIO26 | A-IB | лівий бік |
| GPIO32 | B-IA | правий бік |
| GPIO33 | B-IB | правий бік |
| GND | GND | — |

Клема **MOTOR-A**: обидва ліві мотори паралельно (червоний до червоного, чорний до чорного).
Клема **MOTOR-B**: обидва праві мотори так само.

| GPIO27 / GPIO14 | плата 2, A-IA / A-IB | задній лівий |

**Живлення:**
- Відсік батарей шасі → VCC/GND плати L9110S. Для 2×18650 (7.4–8.4 В) прошивка обмежує ШІМ до 70%
  (`MAX_DUTY_PERCENT`), щоб TT-мотори не перегрівались; для 4×AA (6 В) можна поставити 100.
- ESP32 — від тієї ж батареї через знижувальний перетворювач 5 В на пін 5V (або від USB/павербанка).
- **Земля (GND) спільна** для батареї, драйвера та ESP32 — інакше мотори смикатимуться.
- Мотори ніколи не підключай напряму до пінів ESP32.

Якщо колесо крутиться не в той бік, постав `true` в полі `inverted` цього мотора у `src/main.cpp`.

Диски енкодерів з шасі знадобляться пізніше, з оптичними датчиками швидкості (LM393): для точних
поворотів і їзди на задану відстань.

## Прошивка

1. Скопіюй `speedy-base/include/secrets.example.h` у `secrets.h` і впиши домашню Wi-Fi —
   ту саму, до якої підключений телефон (телефону потрібен інтернет для «мозку»).
2. Встанови [PlatformIO](https://platformio.org/) (розширення VS Code або `pip install platformio`).
3. Підключи ESP32 кабелем і залий прошивку:
   ```
   cd firmware/speedy-base
   pio run -t upload
   pio device monitor
   ```
   Якщо порт не знаходиться — потрібен драйвер CP2102 (Silicon Labs CP210x).
4. Спіді знайде плату сама: поле «Колісна платформа» в налаштуваннях залиш порожнім.
   Шукає при запуску, коли плата перестала відповідати, і на «Спіді, знайди платформу».
   Телефон і плата мають бути в одній Wi-Fi мережі. Адреса плати є і в моніторі порту —
   її можна вписати вручну, якщо роутер блокує широкомовні пакети (режим ізоляції клієнтів).

Перевірка з браузера в тій самій мережі: `http://<адреса>/status`,
`http://<адреса>/move?dir=forward&ms=500&speed=50`.

Якщо домашня мережа недоступна, плата створює точку доступу `Speedy-Robot` (пароль `speedy123`),
адреса `http://192.168.4.1` — для перевірки моторів. Інтернету в ній немає.
