# Колісна платформа Спіді

Залізо:
- **ESP32-DevKitC (ESP-WROOM-32, 38 pin)** на платі розширення — мозок платформи, Wi-Fi.
- **Драйвер L9110S** — 2 канали, до ~0.8 А на канал, 2.5–12 В.
- **Шасі 4WD** з 4 TT-моторами (3–6 В), дисками енкодерів і відсіком для батарей.

**Скільки драйверів.** Моторів 4, а каналів у L9110S 2. Два TT-мотори паралельно на одному каналі
при старті/заклинюванні тягнуть понад 2 А — драйвер грітиметься і може вигоріти.
Рекомендовано **2 плати L9110S**: по каналу на кожен мотор. З однією платою теж працює
(лівий і правий бік — кожен на свій канал, мотори паралельно), але не тримай колеса заклиненими.

## Підключення

| ESP32 | L9110S | Мотор |
|---|---|---|
| GPIO25 | плата 1, A-IA | передній лівий |
| GPIO26 | плата 1, A-IB | передній лівий |
| GPIO27 | плата 1, B-IA | задній лівий |
| GPIO14 | плата 1, B-IB | задній лівий |
| GPIO32 | плата 2, A-IA | передній правий |
| GPIO33 | плата 2, A-IB | передній правий |
| GPIO18 | плата 2, B-IA | задній правий |
| GPIO19 | плата 2, B-IB | задній правий |
| GND | GND обох плат | — |

Мотори — на зелені клеми MOTOR-A / MOTOR-B відповідних плат.
**Одна плата L9110S:** використовуй лише GPIO25/26 (лівий бік) і GPIO32/33 (правий бік),
мотори кожного боку з'єднай паралельно.

**Живлення:**
- Відсік батарей шасі → VCC/GND обох L9110S. Для 2×18650 (7.4–8.4 В) прошивка обмежує ШІМ до 70%
  (`MAX_DUTY_PERCENT`), щоб TT-мотори не перегрівались; для 4×AA (6 В) можна поставити 100.
- ESP32 — від тієї ж батареї через знижувальний перетворювач 5 В на пін 5V (або від USB/павербанка).
- **Земля (GND) спільна** для батареї, драйверів та ESP32 — інакше мотори смикатимуться.
- Мотори ніколи не підключай напряму до пінів ESP32.

Якщо колесо крутиться не в той бік, постав `true` в полі `inverted` цього мотора у `src/main.cpp`.

Диски енкодерів з шасі знадобляться пізніше, з оптичними датчиками швидкості (LM393): для точних
поворотів і їзди на задану відстань.

## Прошивка

1. Скопіюй `speedy-base/include/secrets.example.h` у `secrets.h` і впиши домашню Wi-Fi —
   ту саму, до якої підключений телефон (телефону потрібен інтернет для «мозку»).
2. Встанови [PlatformIO](https://platformio.org/) (розширення VS Code або `pip install platformio`).
3. Підключи ESP32 кабелем і залий прошивку:
   ```
   cd firmware/speedy-base
   pio run -t upload
   pio device monitor
   ```
   Якщо порт не знаходиться — потрібен драйвер CP2102 (Silicon Labs CP210x).
4. У моніторі порту з'явиться адреса, напр. `http://192.168.1.57`. Впиши її в налаштуваннях
   Спіді (довге натискання на обличчя → «Колісна платформа»). У роутері варто закріпити
   за платою цю IP-адресу.

Перевірка з браузера в тій самій мережі: `http://<адреса>/status`,
`http://<адреса>/move?dir=forward&ms=500&speed=50`.

Якщо домашня мережа недоступна, плата створює точку доступу `Speedy-Robot` (пароль `speedy123`),
адреса `http://192.168.4.1` — для перевірки моторів. Інтернету в ній немає.
